## 〇、开赛前3分钟战场阅读（checklist）

1. **找点地形**：11版目标点在地形足印里——数清几个点、哪几块地形是"点地形"

5. **量距离**：家点到中线遮挡区几跳、末日之锤冲边线点的路线

## 二、双烟幕体系（1CP的正确花法·11版已核实）

**两个战略都是"对手射击阶段开始时预开"，别再按10版反应式理解：**

**①通用烟幕（核心战略池15.10）**
```
时机：对手射击阶段开始（预开！）
对象：任一友军SMOKE关键词单位
     ——不限步兵，超重/哨兵/奇美拉都行
效果：该单位＋"被它遮挡的友军单位"
     被攻击时获掩体收益至阶段末
```
标准用法：预判对手要集火毒刃→阶段开始1CP开在毒刃上→毒刃+它挡住的风暴之剑/教士全体吃掩体。**威慑价值**：烟幕竖起对手看得见，常直接逼其改目标。

**②臭气烟幕（指示部队池·官方中文原文）**
```
时机：对手射击阶段开始（预开）
对象：己方星界军步兵烟幕单位
     ＝本表唯一人选：克里格工兵
效果：该单位被打、或"因该单位模型
     遮挡而不完全可见"的单位被打
     →被攻击者获掩体增益
```
工兵前置挡毒刃的打法＝这条。需要工兵提前下车。

**减伤叠加顺序（坦克挨打全套）**：2+甲/教士4++ → 烟幕掩体(命中-1) → 24W血量本钱。

**附：核心池里两条对超重军表重要的**
- **碾碎冲击(1CP)**：T13超重完成冲锋掷13枚D6，5+每枚致命伤（上限6）——末日之锤15寸冲脸+碾碎冲击+岩浆炮近距＝刺客连招
- **巨型不能看守射击**：超重被绕后无快照反制——哨兵/根除者替全军团看住中线

## 五、CP经济（11版规则已核实）

**收入**
- 每个指挥阶段双方各+1CP（你的+对手的）＝**每战斗轮2CP**，开局0CP起步
- 额外CP（音阵回CP等所有来源）**每轮合计上限1**→满打满算3CP/轮
- 先手T1节奏：你的指挥阶段+1（轮内花）→对手指挥阶段再+1（正好留给烟幕）
- 砖的音阵回CP：触发条件是**砖被己方战略指向**（非接命令）——看守射击/英勇介入/反攻等可主动喂；6寸内有军官掷骰+1（5+变4+）；双音阵不叠加。带莱昂图斯后此渠道退休（上限1被他的保证+1占满）
- **不做音阵预期，按2CP/轮做预算；莱昂版按3CP/轮**

**开销优先级（每轮2CP怎么花）**
1. 烟幕1CP——保450分的单位，对手集火轮必开
2. 压制火力1CP——打崩关键单位＝OC归零软夺点＋杀戮计分
3. 碾碎冲击1CP——末日之锤冲锋轮专用（13骰致命伤炸弹）
4. 粉碎齐射1CP——**只**在打蹲掩体高价值目标时开（攻城炮自带无视掩体不需要它）
5. 指令重掷1CP——关键时刻的保险
6. 怒火引擎1CP——被缠住的反打
**纪律**：一轮最多花2CP，集火轮宁可放弃压制火力也要留烟幕的钱；压制/齐射别贪全开

## 六、先手局（回合脉络）

**T1**：
1. 命令：果断命令→Take Aim!群发火力簇
2. 目标优先级：**对手反甲载具＞可见输出单位＞其他**——注意对手未射击步兵若蹲地形，15寸外不可选目标，别浪费火力在"选不了"上
3. 肃清顽敌计分意识：每拆一个单位都在赚VP，优先拆"能拆的"而非"最想拆的"
4. 战略：粉碎齐射1CP（扒掩体）＋压制火力1CP（打崩对面→OC归零）
5. 末日之锤推进冲位；砖粘家点（人在地形足印里）
6. 哨兵标定对面输出王

**T2起**：
- 末日之锤到位→突击舱门下工兵＋Duty and Honour锁点
- 砖开始"地形连跳"推中点（每跳一站=掩体+隐蔽）
- 对面近战贴坦克：不息炮火照常射＋怒火引擎1CP(+6攻+2穿)

**风险预案**：对手反打集火毒刃→烟雾链1CP＋教士4++＋24W硬抗

## 七、后手局（回合脉络）

**对手T1**：你的隐蔽步兵(砖)15寸外打不到、超重在遮挡后选不了——对手只能打毒刃（正中下怀）
**你的T1**：
1. 命令照标准流程
2. 反打优先拆对手**前压的反甲**（他们动了=大多暴露了）
3. 烟雾链在此轮价值最大（对手第一轮集火潮）
**T3+**：
- 信息优势：每轮看对手动完再定命令去向
- 压制火力打关键单位战意→OC归零＝软夺点
- **末轮王牌**：末日之锤冲刺＋突击舱门＋Duty and Honour——最后行动权抢点
