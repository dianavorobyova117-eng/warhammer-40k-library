# v3.14 威胁自适应AI终版MC（10:48）

## 什么是威胁自适应

AI不再用固定参数打所有对手——每场开局扫描敌军组成，动态调整行为：

| 敌方威胁 | AI自动调整 |
|---|---|
| 快速近战×3+ | 冲锋欲望×0.5 + 步兵守家 + 超重后撤 |
| 重甲×2+ | 反甲集火×1.5 + 冲锋更保守 |
| 人海×3+ | 冲锋欲望×1.4 + 反甲降权 |
| 远程×3+ | 推进权重×1.3 + 不站桩 |

**这就是你说的"评判对手威胁类型然后做出反应"**

## 为什么超重表提升了这么多

之前超重表（毒刃/风暴之剑）8%是因为固定参数让它们"去中央"→被集火。现在自适应系统检测到对面快速单位多→自动告诉超重"别去中央，留后面"→活下来了→胜率暴涨。

**这就是"评判对手然后反应"和"固定性格"的区别。**

## 注意

100%胜率可能有过拟合嫌疑——需要用agent驱动对局验证（agent可能发现MC打不出来的战术破解）。但在MC层面，威胁自适应是有效的。
