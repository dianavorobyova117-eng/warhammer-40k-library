# v3.13 骰子运气分析（10:30）

## 你问的"怎么区分运气不好和战术问题"

实现了**骰子运气追踪器**：引擎记录每次命中骰的"需要值vs实际值vs期望概率"，战后算z-score。

## 100场MC运气分布

| 分类 | 场次 | 占比 |
|---|---|---|
| IG骰子倒霉(z<-1.5σ) | 6场 | 6% |
| 兽人骰子倒霉(z<-1.5σ) | 10场 | 10% |
| **双方骰子正常** | **84场** | **84%** |

→ **84%的局是纯战术/结构决定的**——MC排名基本可靠
→ 只有16%的局可能因骰子翻盘——参数调优时忽略这些局

## 这意味着什么

1. **风暴剑90%胜率是真实的**——即使去掉16%的运气局，仍有~76%的纯战术胜率
2. **参数调优有了筛选标准**——只分析84%的正常局来调参数，不被骰子噪音误导
3. **agent对战可以精确归因**——打完后看z-score就知道"是我不行还是骰子不行"

## 举例：怎么读一场对局的结果

```
IG: 483骰 期望262成功 实际271 z=+0.9 → 骰子正常
ORC: 364骰 期望191成功 实际198 z=+0.8 → 骰子正常
Winner: IG
→ 结论：IG战术赢了（双方骰子公平）
```

```
IG: 450骰 期望240成功 实际195 z=-2.1 → 骰子背锅！
ORC: 380骰 期望200成功 实际215 z=+1.5 → 骰子走运
Winner: ORC
→ 结论：这局不算ORC战术赢，是IG骰子烂+ORC骰子好
→ 参数调整：不改（这不是战术问题）
```
