# 钛·蒙特卡 打法手册（大载具版v3-A，2000/1995）

> 2026-09-01 ｜ 适用v3三巨兽版（雷暴+激流+鬼船）
> 框架：团策→主输出→铁丝网→做任务（按用户四要素）

---

## 一、团策：引擎怎么转

```
每射击阶段（FTGG）：
寻路者(观察者)标定一个敌军
→全军打它=导引：命中+1
→观察者带标记关键词→再无视掩体

蒙特卡加成(第1-3轮)：
全军远程【突击】(推进后可射)
导引单位【致命命中】＝命中即造伤
第4轮：强执的"楷模"强化续命
第5轮：掉速，当普通军队打
```
**每轮唯一的战术决策＝标谁**。标定目标就是全军+1命中+致命命中的提款机。

**导引优先给**：弹量最大的（星镰/集束——致命命中按命中数结算）或单发最重的（聚焦炮/磁轨）。

## 三、铁丝网：怎么挡

- **鬼船＝移动铁丝网**：渗透部署站中场，独行者12寸外免疫远程＋隐蔽-1＋**双伤害归零令牌**——对手拆它约等于白扔一轮
- 寻路者×2：侦察7寸前压，双观察者双标记；磁轨队兼守家
- 无隐蔽能力的小队一律**蹲地形足印**（15寸外隐形＋掩体BS-1）
- 蒙特卡1-3轮全军【突击】＝**全员可以边撤边打**——拉扯距离本身就是铁丝网

## 四、做任务：重要资产部署

你的军力部署＝**重要资产（Priority Assets）**：守高价值目标点得分。

- 11版目标点在地形足印里：**守点人优先选有地形可蹲的**
- 家点：磁轨寻路者（蹲地形+15寸外隐形）
- 中场高价值点：鬼船（OC3+钉子属性）或雷暴（OC6，T11W20没人想来翻）
- 计分节奏：T1-3火力窗口期换人数差→T4楷模轮稳住→T5转OC防守
- ⚠️任务矩阵：你和对手的主任务可能不同——看对面分队预判它的部署

## 五、回合脉络

```
T1 全军推进+突击射击(标定+散射/集束洗地)
T2 鬼船钉死中场点，激流新星斩首窗口
T3 致命命中关门前：总攻轮(危机深打进场上,全弹量)
T4 楷模延长轮：稳住节奏
T5 掉速：大兽占点+防守反击
```
