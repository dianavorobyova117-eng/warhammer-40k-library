# 铸锻盟约 Questor Forgepact
**DP消耗：1** ｜ 来源：Wahapedia 11ed（Faction Pack: Imperial Knights v1.2, 2026-08）；交叉：Warhammer Community《Faction Focus: Imperial and Chaos Knights》（2026）

## 分队规则（团策）
### Cogbound Alliance 齿轮盟约
【原】Friendly IMPERIAL KNIGHTS models have the following ability:
Assisted Targeting (Aura): While a friendly ADEPTUS MECHANICUS unit is within 6" of this model, that ADEPTUS MECHANICUS unit’s ranged attacks have: +1 BS. [HEAVY].
Friendly TECH-PRIEST models have the following ability:
Sacristan Pledge: In your Command phase, you can select one friendly IMPERIAL KNIGHTS model within 3" of this model that has not been selected by this ability this phase. If you do, that model heals D3 wounds.
Mechanicus Allies: You can include TECH-PRIEST DOMINUS/TECH-PRIEST MANIPULUS/MARSHAL/RANGERS/VANGUARD units in your army. The combined points value of such units cannot exceed 500 points.

中文速查（逐条）：
- 骑士反向辅助机械教：AM单位在骑士6"内时远程攻击BS+1并获得[HEAVY]
- 技师（TECH-PRIEST）获得 Sacristan Pledge：指挥阶段可为3"内一个未被本能力选过的骑士模型回复D3生命
- 组建特权 Mechanicus Allies：可编入技师主导/操纵者/元帅/游侠/先锋单位，合计不超过500分

## 强化（Enhancements）
| 强化 | 分数 | 效果 | 限制 |
|---|---|---|---|
| 骑士贤者 Magos Questoris | 20 | 使用Sacristan Pledge时，被选骑士额外回复2点生命（D3+2） | TECH-PRIEST模型限定（本队特例：强化给技师） |
| 神工作品骑士 Knight of the Opus Machina（光环） | 15 | AM单位在持有者6"内时，其近战攻击WS+1且AP+1 | 帝国骑士模型限定 |

【原】（Magos Questoris）：TECH-PRIEST model only. When using this model’s Sacristan Pledge ability, the selected IMPERIAL KNIGHTS model heals 2 additional wounds.

## 分队战略
| 战略 | CP | 时机 | 效果 |
|---|---|---|---|
| OMNISSIAH'S GRACE 万机神恩典 | 1 | 任意阶段，骑士单位将受致命伤时 | 该单位对致命伤获得Feel No Pain 5+ |

【原】（VENGEANCE OF THE MACHINE CULT）：That enemy unit is marked until the end of the battle: While a unit is marked, friendly ADEPTUS MECHANICUS units’ attacks that target that unit can re-roll wound rolls.

## 组建限制（若有）
- Mechanicus Allies：仅可编入 TECH-PRIEST DOMINUS / TECH-PRIEST MANIPULUS / MARSHAL / RANGERS / VANGUARD 五类单位，合计≤500分
- FAQ（Wahapedia载）：这些AM单位**不能**使用 Doctrina Imperatives 能力（"Can Adeptus Mechanicus units use the Doctrina Imperatives ability when taken as part of the Questor Forgepact Detachment? — No."）

## 战术画像
- 1DP混编流：骑士+500分机械教，AM小队白嫖BS+1[HEAVY]，技师给骑士奶血
