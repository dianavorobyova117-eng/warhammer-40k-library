# 恐惧突袭小队（Phobos Strike Team）游玩手册 — Kill Team 3.0

> **定位**：6人福博斯甲星际战士——**全员APL3·移动7寸·无限射程卡宾枪·无重型限制·双射击**。
> **这不是站桩狙击队。这是全游戏最纯粹的移动火力平台。**
> **数据基线**：Wahapedia Phobos Strike Team（Nov '25版），核验日 2026-09-20。

## 一、队伍概况：为什么是跑射

| 参数 | 数值 | 含义 |
|---|---|---|
| APL | **全员3** | 每激活3个动作 |
| 移动 | **全员7寸** | 全游精英队顶级机动 |
| 甲 | 全员3+ | 星际战士标准 |
| 血 | 12~13 | 精英底子但不是最厚 |
| 射程 | **全员无限距离** | 没有一杆枪印了射程 |
| 重型 | **没有**（唯一例外：破坏专家遥控起爆器） | 移动后照常射击 |

**四个数字放在一起的含义**：
- 无限射程 → 你不需要选射击位，只需要视线
- 无重型限制 → 你不需要站桩，移动后照常开火
- APL3 → 转移+射击+射击 = 跑完就打两轮
- 7寸移动 → 每轮换一个大射击位

**对面面对的画面**：6个星际战士在废墟间不停换位、每轮12颗骰子的精确火力——上一轮他们还在那个废墟后面，这一轮已经绕到24寸外的另一个窗口了。

## 二、阵营规则精讲

### 全向扰频器 Omni-Scrambler
战略奇策（需场上有友方渗透者）：选一名**对友方渗透者可见、或在友方断讯兵6寸内**的敌人；其后的交战阶段中该敌人不能被激活/执行动作，直到对手已激活敌人数=宣言时场上友方渗透者数、或其成为最后一个待激活敌人。免掷骰。你的6人全是渗透者时效果最大化。

### 恐惧 Terror
掠袭者3寸内的敌人：做任务+1AP、争夺APL-1。不杀人的软控制。

### 阿斯塔特 Astartes
双射击（至少一发爆弹）或双近战；无视命令乘隙。**没有+1AP条款——所有爆弹卡宾枪双射零额外成本。**（与死亡守望不同，DW的重武器双射要多花1AP。）

### 多光谱阵列 Multi-Spectrum Array
先遣者射击时敌人不可被**遮挡**（无视重地形介入的弃1骰+暴降普惩罚）。⚠2026-09-28核验更正：**遮挡≠掩体**——多光谱只消遮挡惩罚，**不能让隐蔽+掩体中的目标变为可选**（隐蔽目标可选性=可见+不在掩体中，见规则速查第16条）；破隐蔽掩体目标靠换射角或贴2寸。

### 数据卡补注（2026-09-21 Wahapedia Nov'25原文核验补全）

- **通讯阵列**（渗透通讯兵）：每TP一次，在某友方干员的激活或乘隙期间（动作前后）执行——**改变你本TP已用过的一个战略计策**（不耗CP）。精确语义（重用还是替换）页面原文止于此，FAQ空缺。**2026-09-29用户App实操口供闭环：语义=替换**——把本TP已宣言的战略计策替换成另一张（不耗CP）；标准用法=射手用完致命射击后，通讯阵列将其替换成"游击战"，使通讯兵（APL2移动+射击已满AP）射完免费切回隐蔽令。
- **遥控起爆器·引爆**（渗透破坏专家）：武器4/2+ 5/6 穿1·静音·限1·**重型(仅疾行)**。引爆=不选目标，对**爆炸物标记2寸内每名干员**各射一轮（重型地形完全阻隔者除外）；这些目标不能受掩体/遮挡保护；各序列按自选顺序**单独结算**；动作结束移除标记。近战房规则杀伤区中另带致命5+。
- **星标扫描**（渗透断讯兵，1AP）：至本干员下次激活开始或阵亡——友方射击**其8寸内**敌人时该敌不可被遮挡；若射击者是**先遣系**干员，其远程武器同时带**寻敌光 Seek Light**（定义在附录，文本待查）。
- **电磁雷+感应雷**（先遣布雷兵）：电磁雷=携带标记可捡放，**不能放在敌方控制范围内**；感应雷=标记首次进入其他干员控制范围→移除标记，该干员**APL-1至其下次激活结束+受2D3+3伤**，存活则动作立即结束（布雷兵本人免疫）。
- **掠袭系武器为部署时二选一**（特种爆弹手枪8寸穿1+战术刀5/3+ 4/5，或爆弹卡宾准确1+拳头），非同时持有。

## 七、选人：定死与取舍

**三系分工**：渗透系=全向扰频器的计数器（场上每多一个渗透系干员，锁人多1个激活）；先遣系=多光谱阵列载体（先遣系射击时敌人不可被遮挡）+全队输出上限（唯一2+在这系）；掠袭系=恐怖光环+重力降落伞机动。选人四问：**谁产指挥点（通讯兵）、谁吃平衡当输出（射手/士官）、谁提供时序否认（渗透系数量+断讯兵）、谁守点做任务（布雷兵/破坏专家/战士）**。**选人限制（2026-09-28补）**：除三种战士（WARRIOR关键字）可重复外，每种干员限选1。

- **定死**：渗透士官/先遣士官（领袖）、**渗透通讯兵**（CP引擎）、**先遣射手**（2+全队最强单发）。
- **强烈推荐**：渗透老兵（定制卡宾按对手配规则）、渗透破坏专家（遥控起爆器反重甲+布雷控点）。
- **取舍**：掠袭战士（Terror控点+近战）↔先遣布雷兵（诡雷守点）↔渗透断讯兵（反重投）↔渗透战士（任务件）。

## 九、激活链与配合链（跑射循环）

### 标准轮（跑射）

1. **渗透士官**：转移+双射击（双射由阿斯塔特规则自带、不耗计策；⚠0CP券只能用于**交战**计策，致命射击是战略计策——0CP用不了）
2. **渗透通讯兵**：双射击/调整
3. **渗透破坏专家**：转移+射击（遥控起爆器优先打高价值）
4. **渗透老兵**：转移+双射击（定制规则输出）
5. **先遣射手**：**警戒（追踪目标）**——任意杀伤区可架、隐蔽令也可架（打断射击时自动转交战）；或机动+射击
6. **掠袭战士**：近战补刀或贴点Terror

### 跑射循环的核心

**每轮全队转移+射击=对面面对的是12颗移动中的精确骰子**。对面打不到你的当前位置（因为你上轮就跑了），打不到你的下个位置（因为你下轮又换了）。**你6个人在对面半张地图上不停换位、不停输出、不停做任务**——对面的近战件永远在追你的残影。
