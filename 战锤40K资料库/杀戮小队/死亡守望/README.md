## 队伍速览

- **编制**：5人（全游最小编制档），从11个选项选5，各限1，GRAVIS重甲（炮击者/破障者/屠群者，18血40mm）最多1。
- **原型**：猎杀&肃清 / 警备。全员APL3、甲3+（盾卫2+）、血13-18。
- **引擎**：老兵阿斯塔特（双动作+乘隙带1免费动作）；特种弹药每回合点换一种全队弹药；士官每场两张0CP计策券。
