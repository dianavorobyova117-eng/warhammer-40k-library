# 死亡守望（Deathwatch）游玩手册 — Kill Team 3.0

> **定位**：纯精英队教科书。全游最小编制（5人），用行动密度、时序否认和自适应弹药把"人数差"打回来。
> **数据基线**：Wahapedia Deathwatch Jan '26 版 + 官方队伍规则PDF（2026-01-28），核验日 2026-09-18。**注意：2026年1月平衡档对死亡守望砍了多刀，本手册基于砍后现行文本**——2025年12月及更早的社区攻略强度评价已过时。
> **配套文件**：`数据卡_中文.md`（11张数据卡中文全译）、`官方队伍规则_EN_2026-01-28.pdf`（官方原图）。

## 一、阵营与队伍概况

死亡守望是审判庭的异形猎杀武装——从各战团抽调的老兵组成的"全明星"。KT3.0 里他们是**纯精英队的极端**：

- **5人编制，全游最小编制档**。从11个选项（守望士官 + 10种专精老兵）选5，各限1，**GRAVIS重甲（炮击者/破障者/屠群者）最多1名**。
- 全员 APL3、甲3+（盾卫2+）、血13~18——每人都是别人队里的"精锐件"，而且每人每轮**双射击或双近战**。
- 盒装：Kill Team: Tomb World（2025-08预购），死亡守望10模型=两支5人队 + 死灵Canoptek Circle 12模型 + Tomb World地形。
- **版本史**：2025-S2 入场即巅峰（12月社区称"版本双雄"）→ **2026年1月平衡档挨了最重的几刀**（Veteran Astartes被修改、重武器双射击+1AP）→ 4月/8月档未再动。当前定位：**被削一轮后的中上强度队**——休闲局完全够玩，但别按削前攻略期待"版本答案"。

**这队的乐趣公式**：5个专精完全不同的角色 + 每回合换一种"子弹" + 每轮免费按住对面一个人。选人即选战术，是对抗选队伍的最佳载体。

## 二、规则精讲

### 2.1 老兵阿斯塔特（Veteran Astartes）——行动密度引擎

- 每个干员每激活**双射击或双近战**。
- **+1AP条款**：双射击时若两次都用 辅助榴弹发射器 / frag炮 / 重型等离子喷射 / 炼狱重爆弹 / 等离手枪 / 猎潜步枪，或任一次用热熔炸弹，第二射+1AP。
  → 实务含义：**地狱风暴爆弹步枪（破障者）与爆弹手枪可以免费双射**；重武器组（炮击者/枪手/神射手重档）双射要3AP（APL3刚好），或"移动+单射"2AP。
- **乘隙强化**：无视命令乘隙，且乘隙=**免费多做1个1AP动作**（两动作须不同；同次乘隙不能又射又砍）。
  → 5人队人数少的官方补偿：每个耗尽的老兵在对手回合站起来补一手，**乘隙=2动作的小激活**。配合奥术预告追踪（乘隙时改命令）——打完切隐蔽，防止对面乘隙反咬。

### 2.2 特种弹药（Special Issue Ammunition）——每回合换一种子弹

每回合点一次：任一干员射击时，给自己的远程武器临时挂**一条**（至该动作结束）：
**Blast 1寸**（Torrent武器不可选）· **Devastating 1** · **Lethal 5+** · **Piercing Crits 1** · **饱和** · **Severe（严重：未保留暴击时1普成升暴）**

**挂法决策**（每回合问一次"今天打什么"）：

| 场景 | 挂什么 | 给谁 |
|---|---|---|
| 目标躲掩体/被遮挡 | **饱和** | 神射手/枪手/炮击者 |
| 3+甲精英 | **穿暴1**（暴击更疼）或 **致命5+**（更多暴击） | 等离喷射/frag炮/猎潜 |
| 扎堆 | **Blast 1寸** | 非Torrent武器（frag炮榴弹弹、等离、卡宾） |
| 目标残血想保收 | **Severe** | 神射手/卡宾（严重=无暴时普成升暴） |
| 高血量处决 | **Devastating 1** | 每颗保留暴击多钉1点 |

（弹药储备装备：每场一次，同一回合点内用两次、须不同规则——这就是"处决回合点"的双倍弹药窗。）

### 2.3 计策速查

**战略（各1CP）**：任务战术（宣言隐蔽/交战——全队对相应命令敌人**平衡**，开战按对手预判宣言）；弑盾者（深入敌半场时4+普伤减1）；长夜守望（己方半场被射重投1防骰）；无所畏惧（无视受伤减益）。
**交战（各1CP）**：决不容异形（对**无混沌且无帝国**关键词目标重投任意攻击骰——⚠**对混沌/帝国对手是死科技**，常见对手多为混沌/帝国阵营，多数对局吃不到）；高级奥术扫描（射击时饱和+敌人不可被遮挡）；奥术预告追踪（乘隙时改命令）；超人体质（防御普成升暴）。

**士官的战略指挥**：每场各一次——**0CP**用一张战略计策 + **0CP**用一张交战计策。用法：战略那张给任务战术（TP1）；交战那张留给对面冲锋轮的超人体质，或你处决轮的奥术扫描。

### 2.4 装备（士官在场=5选）

| 装备 | 评价 |
|---|---|
| **圣所-V生物扫描腕** | **近必带**。每个干员每次激活一次：回D3血／清APL变化／拆中子碎片·毒素·恐惧化学标记——13~18血的身体配每轮回血，硬度社区共识的来源 |
| 弹药储备 | 处决回合点双弹药（不同规则）——爆发窗口 |
| 数字武器 | 每回合点一次：近战掷攻击骰步骤开始时对序列中敌人**独立造成1伤**（非攻击伤害+1）——近战配置选 |
| 掠析伺服奴颅 | 任务动作-1AP，且敌人在其**控制范围内**也可做任务动作（仅此时才掷对骰赌装备）——任务流选 |

（另有通用装备：杀伤雷2颗/效用雷烟晕/梯子2把/路障等——见第五章装备方案。）

## 四、选人：定死与取舍

### 4.1 定死

- **守望士官**：两张0CP计策券+装备+1、15血3+甲——没有任何理由不带。
- **干扰者（九成局面）**：全向扰频器是全队唯一的"时序否认"，每回合免费锁对面一个激活；奥术三角测量白送枪手"饱和+不可遮挡"。**对5人队来说，按掉对面的激活=变相增加自己的激活。**

### 4.2 Gravis 三选一（按对手定）

| 对手 | 选 | 理由 |
|---|---|---|
| 精英枪阵/蹲点 | **破障者** | 热熔炸弹拆锚点+Torrent清漏 |
| 集群/人墙 | **屠群者** | 三档炼狱重爆弹是反集群天花板，18血站走廊 |
| 混合/你需要火力压制 | **炮击者** | 5/7穿1无限射程artillery，18血最肉 |

### 4.3 非Gravis 三选二（干扰者/神射手/刀主/斩首者…按对手）

- **对近战队（复仇之爪类）**：干扰者 + **刀主**（下神射手）——大盾+刀主两把锁把对面的冲锋件双双按进决斗，相位横扫惩罚扎堆。
- **对射击/蹲点队**：干扰者 + **神射手**（下刀主）——5杆无限射程枪对射不虚，警戒哨惩罚换位。
- **对暗杀/偷跑队（狼侦察类）**：干扰者 + **神射手**，全员保持"冲锋圈外1寸"，警戒哨专治偷跑。
- 其余候补：**斩首者**（对后排脆皮阵容的暗杀解）、**破坏者**（对面有雷神锤级近战时对锤）、**枪手**（等离炮台，泛用第五人）、**Aegis**（对面近战/穿甲强则定死）。

**泛用默认五人组**：守望士官 + 盾卫 + 枪手(重型等离) + 干扰者 + 神射手/刀主（按对手二选一）。
**明确短板**：①反集群为零（全单目标武器）②大盾是唯一近战体 ③激活贫困结构性存在 ④中场机动只靠干扰者。按对手换人缓解，无法根除——这是5人队的设计代价。

## 五、装备：两套方案（士官军械库适应=5件）

### 方案甲「烟盾据点」（推荐·阵地消耗画风）

**圣所-V护腕 · 掠析伺服奴颅 · 弹药储备 · 效用雷(双烟) · 梯子(2把)**

- 打法：大盾（或盾卫）顶中场插销——脚底扔烟（对2寸外敌人=弃1骰+暴击降普），敌人1寸外想点射他会被你的反应枪线打死，冲进1寸就是进大盾的近战回合；伺服颅让他**在敌人1寸内也能做任务动作**（掷骰赌装备）；梯子让等离子枪手/神射手/干扰者TP1~2快速上楼架炮台/警戒。
- 细节：扔烟不能在敌人控制范围内（先扔再站进去）；烟只活一个回合点（下回合点掷D3个激活后或结束时散）、全场两次；**烟不挡近战**；烟里开枪对外也吃遮挡（大盾的手枪无所谓）；**梯子是公共地形，敌人也能爬**——梯顶出口架在枪线交汇处。
- 服役干员：大盾/盾卫是插销最佳人选；次选任务使型需求时上伺服颅本体。

### 方案乙「处决火力」（爆发画风）

**圣所-V护腕 · 弹药储备 · 数字武器 · 杀伤雷(2穿甲) · 效用雷(晕)**

- 打法：弹药储备开处决轮双弹药（饱和+穿暴1同回合挂两杆枪），数字武器给近战组+1伤，晕雷-1APL拖对面引擎。
- 注意：杀伤雷的**穿甲/破片在布阵时秘密选定、开局不能改**——朋友圈全是3+甲→默认2穿甲；确认纯人墙才2破片。

（若想梯子+杀伤雷都要=6件超限，砍弹药储备，保留护腕/伺服颅/效用雷。）

## 六、玩法：激活链与配合链

### 6.1 激活贫困的三大补偿（死亡守望的核心课题）

1. **双动作密度**：5人=10次动作，人人APL3。
2. **强化乘隙**：全耗尽后的每次乘隙=免费动作+附加动作=2动作小激活；奥术预告追踪还能顺手改命令（打完切隐蔽防反咬/隐蔽埋伏切交战偷袭——官方设计者评述原话）。
3. **全向扰频器**：每回合把对面一个激活按掉1~6手。

### 6.2 TP阶段论（5人版）

- **TP1 走位轮**：不接触。梯子上楼/伏击台占位/插销走到走廊口；士官0CP战略计策给任务战术。5人队TP1死人是最大事故。
- **TP2~3 厮杀轮**：扰频器+特种弹药全开，双射击逐个点名。优先级：①对面的近战腿（让他够不到你）②对面的引擎位 ③任务干员。
- **TP4 残局**：5人队血贵——绝不送人；乘隙+警戒哨榨干剩余价值；任务分优先于击杀。

### 6.3 点杀前置清单（精英队版）

① 扰频器是否锁住了会救他的那个人？② 特种弹药挂对了吗（对甲=穿暴/致命，对掩体=饱和或奥术扫描）？③ 神射手是站桩吗（重档Dash限定，动过打不了）？④ 热熔炸弹每场1次——确定要在他身上用掉？⑤ 伤害估算≥目标血量？5人队的激活浪费不起。

### 6.4 距离与视野纪律

- 静态武器（狙/热熔/重等离双射/frag炮）激活内**不动**——上楼/转移和开枪分在两个激活。
- 大盾/插销永远走在枪位**前1寸**，且**不要**贴在枪位1寸内（你近战咬住的敌人会挡住队友的射击）。
- 干扰者7寸机动，保持"能看见要锁的人"的同时站在对面冲锋圈外。
- 烟盾（若用方案甲）：烟里对2寸外开枪自己也吃遮挡惩罚——大盾主打近战，手枪无所谓。

## 八、强度定调与社区观点

- **当前定位**：2026年1月挨砍后的**中上强度**精英队。双动作/乘隙/SIA/扰频器引擎全部健在，被砍的是重武器双射的成本与部分弹性。
- **社区观点（2025-12 B站，已过时部分标注）**："很硬（减伤+重骰）、枪强刀（除盾卫/雷锤）吃亏、5人怕人多偷跑"——这三条现行仍成立 ✓；"对狼侦察64开偏DW"——**已过时**（1月DW挨砍+狼4/8月才被削），当前对位最多五五；"数值高就是简单好玩"——砍后是"数值扎实"。
- **对位精算参考**：狼群领袖先手双近战可秒盾卫（评论区骰子数学，现行数据卡下依然成立）——盾卫是反穿甲决斗坦，不是无敌坦。
