## 通用核验要点（写新队手册时必查）

- 面板=普伤/暴伤；无射程印=无限距离；Piercing=防守方少x骰；饱和=禁掩体豁免
- **隐蔽目标可选性=可见+不在掩体中（无6寸规则）**；掩体=介入地形贴目标1寸内；遮挡=重地形介入（只罚不挡）；破隐蔽掩体=换射角/贴2寸/寻敌类规则
- 控制范围=可见+1寸；冲锋=移动+2寸（近战独立1AP动作）；近战=对刀（双方各掷自己武器攻骰）
- 射击三道门：可见→目标1寸内无己方干员→遮挡惩罚照吃
- 同名武器规则不叠加（附录总则；唯一例外=精准合一为2）；严重Severe=无暴击保留时1普成升暴
- 平衡档：2026年1月/4月/8月；引强度必带月份；计策CP费用Wahapedia普遍不印（惯例1CP，App终审）
- 中文渠道规则文本需回英文原文对读（已知差异：饱和、扰频器或/且、医疗neither-nor）
