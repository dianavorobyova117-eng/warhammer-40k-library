# 猎手团（Hunter Clade·机械教猎手）游玩手册 — Kill Team 3.0

> **定位**：机械教第二支队——10人**训令引擎队**：每回合点战略奇策切换全队训令（护教者远程不息/征服者近战不息/壁垒者减伤/进击者加速/中立），**每条训令自带代价栏**（优化+劣化同时生效）；Sicarian双系（渗透者静音+锈蚀者双刀）+Skitarii双系（游侠狙/先锋辐光环）。**Volkus原生队**（Sedition's Gate赛季配套）。
> **译名说明**：Hunter Clade=猎手团（通行译名"猎手族"）；Sicarian=西卡里安（渗透者/锈蚀者）、Skitarii=斯基塔里（游侠/先锋）。
> **数据基线**：Wahapedia Hunter Clade，核验日 2026-10-14（编制/五训令全文/14卡/4+4计策/4装备全量——截断禁令+区块目录验证流程执行）。原型：Seek & Destroy / Recon。

## 一、编制（10人）

**1队长**四选一：**西卡里安渗透者王子**（针叶爆破器或卡宾枪＋动力武器或电击杖）／**西卡里安锈蚀者王子**（和弦爪双档二选一）／**斯基塔里游侠组长**／**斯基塔里先锋组长**（组长配装=电流步枪或精工镭手枪＋动力武器；或电弧手枪/磷爆手枪＋电弧锤/电击杖）。
**9选**：**渗透者战士**（针叶爆破器或卡宾枪＋动力武器或电击杖）／**西卡里安战士**（和弦爪&音刃刀 或 音刃双档）／**游侠/先锋各系**（Diktat／Gunner（电弧步枪/等离卡宾/铀狙击枪三选一）／Surveyor／战士）。

**选人限制（2026-10-15补录原文——此前整段漏写）**：
- Gunner与战士系可重复，**其余各限1**（Diktat/Surveyor/渗透者/西卡里安战士各1）；
- **至多1个Diktat、至多1个Surveyor、至多5个Sicarian系**（渗透者+锈蚀者合计上限5）；
- **全队至多1把电弧步枪、1把等离卡宾、1把铀狙击枪**（三杆重炮各一——想双铀狙是非法的）；
- 带*号干员（渗透者战士/两类Gunner）合计至多7名。

**骨架**：全员APL2/6寸/4+甲；Sicarian系10~11血、Skitarii系7~8血。

## 二、阵营规则：训令 DOCTRINA IMPERATIVES（每TP切换的全队模式）

选人结束选一条**主模式**（整场标记——注意：主模式不自动生效，仍需按下面奇策宣言；唯一特权=**每场一次宣言主模式时可忽略其劣化栏**）。
**战略奇策**：选一条训令，全队持有至下TP战略阶段准备步——**优化与劣化同时生效**：

| 训令 | 优化 | 劣化 |
|---|---|---|
| **护教者 Protector** | 全队远程**不息** | 近战命中恶化1 |
| **征服者 Conqueror** | 全队近战**不息** | 远程命中恶化1 |
| **壁垒者 Bulwark** | ≥3的普伤对己-1 | 移动力-1寸 |
| **进击者 Aggressor** | 移动力+1寸 | 甲值恶化1 |
| 中立 Neutral | 无 | 无 |

→ 每TP的形态切换决策：对射回合护教者（接受近战劣化——反正你不近战）、被冲脸切征服者、换血期壁垒、抢点轮进击。**主模式选择建议=壁垒者**（唯一"劣化可忍"且每场免劣化一次最超值）。

## 五、交战计策（4条）

| 计策 | 效果 |
|---|---|
| **控制敕令** | 轮到你激活时：选队长+其3寸内可见另一就绪者——正常激活其一，**耗尽后另一人立刻激活（跳过对手）**——连锁双激活（海军跳帮破门清障同款） |

| **万机神训令** | 激活中/被射掷骰步骤后：至下TP该干员按当前训令获得**超频版**——护教者→远程带**严重**；征服者→近战首刀结算后**立即再结算一颗**；壁垒者→**甲+1且被射多掷1颗防御骰**；进击者→移动+1基础上〔超频效果见原文App〕；若在Shoot动作中用则甲值立即生效（超越动作内不变规则） |

## 八、核心打法与数字（2026-10-14引擎，vs 13血3+甲无掩体）

**训令节奏**：TP1中立/护教者试探→TP2护教者（电流步枪海+瞄准协议致命5+——不息重投兜底）→被贴脸切征服者（锈蚀者近战不息+加速剂双刀）→换血期壁垒。**指令覆写**让前排锈蚀者在护教者回合单独吃征服者——形态混合流。
**数字**：

| 枪 | 期望（13血3+甲） | 定位 |
|---|---|---|
| **铀狙击枪站定**（Dev3+严重+穿1） | **10.85、杀33.8%** | 火力天花板（比DKK同款狙击多严重词条） |
| 等离卡宾超载 | 9.02、杀18.8% | 副炮 |
| 电流步枪+瞄准协议 | ~6.3 | 海（不息+致命5+重投后实际更高） |

**双光环体系**：先锋辐饱和（2寸内敌命中恶化1+弱化辐照普伤-1+辉光攻-1——三层叠满的贴脸debuff场）+渗透者神经静电（6寸禁重投）——**这队的防御一半靠训令一半靠"你站进来就变弱"**。
**连锁**：控制敕令（队长+3寸内双人连动）+极遣心智链变体——时序武器。
