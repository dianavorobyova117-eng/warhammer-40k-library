## 关键KT3.0规则（已核验原文，分析时必查）

### 行动与结算
- 每激活=选命令→执行动作→耗尽；AP≤APL
- 同一激活不能执行两次相同动作
- 两次射击是**独立结算**（各有攻防骰），不能合并算
- 增益按次生效（交战计策/装备=一次性；战略计策=持续到TP结束）

### 控制范围
- 控制范围 = **可见 + 1寸**
- 冲刺/撤离/警戒均不能在控制范围内执行
- 射击不能在控制范围内执行（对任何敌人）

### 近战
- 冲锋 = 移动+2寸，必须结束在控制范围内
- **近战(1AP)是独立动作，不包含在冲锋里**
- 反击在**同一动作内**结算（双方攻击骰同时掷）
- 近战死 = 被救者必在敌人1寸内 = Medic!条件失败 = 救不了

### 射击三道门
1. 目标可见
2. 目标1寸内无己方干员（不打进近战）
3. 遮挡惩罚照吃（弃1骰+暴击降普伤）；掩体豁免可被饱和类剥掉

### 面板读法
- 伤 3/4 = **普伤3 / 暴伤4**（第一个数是暴击）
- 无射程印 = **无限距离**
- 穿X = 防守方少收X颗防御骰
- 饱和 = 防守方不能保留掩体豁免
- 致命5+ = 攻击骰5+为暴击
- 重型(Dash限定) = 只能Dash后射击
- 静音 = 隐蔽状态下唯一可射击的武器类型
- Devastating X = 每颗保留暴击立刻 inflict X 伤（该骰不弃）
