# 强征小队（Exaction Squad / 法警）游玩手册 — Kill Team 3.0

> **定位**：帝国法警执法队——10~12人半精英，全游戏最好的"城堡"画架：3+甲盾兵当大门、执行者霰弹枪当炮台、镣铐+镇压锁死对面的一切位移与反击。
> **数据基线**：Wahapedia Exaction Squad（**Jan '26版**），2026-09-28全文重审计（10次抓取、关键数值≥2次交叉；v4修订=8错误+9缺漏+3缺口补全+3条漏收计策）。
> **阵营装备（4件）**：强化镜面护目镜 / 镣铐 / 频闪磷光灯 / 特制弹药。

## 一、队伍构成（1领袖+10选；枪手最多2、盾兵最多4、警戒者不限，其余各限1）

> ⚠2026-10-26原文更正：旧版"各限1；盾兵最多2"系抄录错误。Wahapedia原文："Other than GUNNER, SUBDUCTOR and VIGILANT operatives, your kill team can only include each operative on this list once."＋"up to two GUNNER operatives (each must have a different option) and up to four SUBDUCTOR operatives."——即**盾兵上限4**（用户指出，当日重抓核验）；VIGILANT（警戒者）在"各限1"豁免名单内且无上限条款=不限。

**1 监督官-执行长 PROCTOR-EXACTANT**（领袖）：战斗霰弹枪(近档4/**2+** 4/4 射6 / 远档4/4+ 2/2)+射击手枪(4/3+ 3/3 射8)+**支配锤&突击盾 4/3+ 4/4 致命5+·Shock·镇压\*** 或镇压警棍(3/**3+** 2/3)。**突击盾**：带盾时甲升3+。
**部署鹰徽徽记（0AP·免费）**：鹰徽标记不在场→放置于本干员水平6寸内；已在场→水平移动最多6寸。不可在敌方控制范围内执行。本干员离场（含被放倒）则移除。
**鹰徽效应**：鹰徽（未放置时改为以监督官本体为中心）3寸内的敌人——执行**拾取标记与任务动作多花1AP**；判定任一标记控制权时，参与争夺的敌人中至少一人在3寸内→其APL合计视为**-1**（非属性修改，可叠加）。

**10选**（枪手最多2、盾兵最多4、警戒者不限，其余各限1）：惩戒官 / 军医 / 链主 / **机械犬R-VR** / 标记官 / **神射手** / 宣判官 / **防暴盾兵（最多4）** / 警戒者（不限） / 通讯士 / 枪手（榴弹发射器·重爆弹·网枪三选一，2把须不同选项）。

## 二、阵营规则（3选1，已核验全文）

1. **无情效率**：法警干员射击（杀伤雷除外）选目标时——**其他法警干员在目标1寸控制范围内不再阻止选择该目标**。⚠官方勘误：只豁免法警同伴；你的**非强征**审判庭干员在敌人1寸内照样锁死目标选择。
2. **正义标记**：奇策。选一个敌人作为你的标记直到回合点结束。友方法警干员对标记射击/近战/反击时武器带**Punishing（对手不能用普成格挡你的暴击）**。标记倒地→该动作结束移尸后可换标（可连续）。
3. **镇压 Repress**：全队部分武器（警棍/支配锤/拷问锤/电击警棍&盾）获得**Repress武器规则**——**你的每个格挡可以挡2个未结算成功（代替1个）；若该干员在反击，你先结算第一颗攻击骰（防守方先出刀）**。

## 六、选人：定死与取舍（"城堡执法"框架）

- **强烈推荐**：标记官（VERISCANT=不花CP的全队致命5+严酷，和神射手锁定组合）、网枪枪手（定身）。

## 七、激活链与配合链（城堡执法三段式）

- **TP1 布阵**：盾兵×2卡两条走廊口；神射手上堡垒（OPTICS架好）；军医在神射手身后3寸；标记官跟主力；**监督官鹰徽放在中场任务点旁**（敌人做任务+1AP+争夺APL-1）。链主的攻击形态奇策：对近战队选凶猛+迅捷。
- **TP2 火力轮·上**：VERISCANT标记对面冲锋腿→神射手站桩霰弹（4/2+全4伤Dev4+致命5++严酷=一枪4~8伤）→盾兵吃第一波冲锋。**终极判决**让6寸内全体霰弹带平衡。
- **TP3 火力轮·下**：军医2D3治疗；网枪定任务手；**精准惩罚**白嫖反击；执行令打断占点敌人。
- **TP4 残局**：盾兵钉点+镣铐锁撤离；射手清残。
- **点杀前置**：VERISCANT标记→神射手站桩+OPTICS→军医在救援位——三件套齐=对面一个精英每轮稳定蒸发4~8血。
