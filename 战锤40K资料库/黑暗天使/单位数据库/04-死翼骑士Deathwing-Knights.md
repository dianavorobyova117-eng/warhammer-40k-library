## 能力

### 核心能力
**深打（Deep Strike）**；阵营能力：时刻之誓。

### 传送信标 Teleport Homer（原文）
【原】"At the start of the battle, you can set up one Teleport Homer token for this unit anywhere on the battlefield that is not in your opponent's deployment zone. If you do, once per battle, you can target this unit with the Rapid Ingress Stratagem for 0CP, but when resolving that Stratagem, you must set this unit up within 3" horizontally of that token and not within 8" horizontally of any enemy models. That token is then removed."
开战时可放1枚传送信标（对手部署区外）；每场1次以**0CP**对本队用"快速入场"——必须落在信标3"内且距敌≥8"。
※阵营包errata：9"→**8"**。

### 内环 Inner Circle（原文）
【原】"Each time an attack is allocated to a model in this unit, subtract 1 from the Damage characteristic of that attack."
每次分配到本队的攻击**伤害-1**（D2变D1，D3变D2）——顶级肉度，注意在分配时即生效。

### 黑暗守望者 Watcher in the Dark（装备能力，阵营包v1.0更新）
【原】"Once per battle, in any phase, just after a mortal wound is allocated to an ADEPTUS ASTARTES model in this unit, this unit can summon a Watcher in the Dark. When it does, until the end of the phase, models in this unit have the Feel No Pain 4+ ability against mortal wounds."
每场1次：本队阿斯塔特模型吃到致命伤后立即触发，本阶段全队对致命伤**4+痛觉无效**。

## 战术备注
- 240分=肉度之王：T5/2+/4++/每模型4W+**减伤1**——除高S重击外几乎啃不动
- 反怪锤对巨兽/载具4+暴击即伤——9折时的坦克开罐器；对步兵则换动力武器
- 配"死翼突袭"强化（15分）：第1-3轮无视任务规则深打——绕过部署直接砸后排
- 用户表配置"赦免之锤×5"实际是团长不恕巨武器+4锤；需精确请改模或确认
- 与死翼终结者的选择：骑士=纯近战绞肉机（更肉），终结者=射击+混合（更活）
