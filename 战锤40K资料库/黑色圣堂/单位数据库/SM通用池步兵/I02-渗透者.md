## 能力

### 核心：渗透者 Infiltrators
部署阶段可部署在己方部署区外的任何位置（非敌方控制）。

### 全频干扰器 Omni-scramblers（原文）
【原】"Enemy units that are set up on the battlefield from Reserves cannot be set up within 12\" of this unit."

## 战术备注
- **开局无主之地的主人**：渗透部署直接站中场目标——比侦查小队(65)硬（W2+3+甲）但贵45分
- 全频干扰器：贴着对手预备役入场点放，深打流（终结者/空降兵）直接断路
- 通讯阵列版＝CP回血器：被战略照顾时56%回1CP，长局价值高
- 110分5人版性价比最高；10人版只在需要锁大点时考虑
- BT誓言"捍卫帝皇荣耀"（步兵锁点）下渗透占点直接触发
