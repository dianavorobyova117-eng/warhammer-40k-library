### 陨星降落 Meteoric Descent（原文）
【原】"In your Movement phase, when this unit is set up on the battlefield using the Deep Strike ability, it can perform a meteoric descent. If it does, this unit can be set up anywhere on the battlefield that is more than 6\" horizontally away from all enemy units, but until the end of the turn, it is not eligible to declare a charge."

## 战术备注
- **125分空降火力砖**：3人6支突击爆弹枪=18攻S5/-1/D2持续命中2——落点即清场步兵分队
- 等离子版：6发S8/-3/D3超载——反甲空降兵，危险骰需谨慎（3人6粒超载≈1自伤）
- 陨星降落6寸贴脸：18寸射程内指哪打哪；本轮别冲锋，射完靠T6/W3站桩
- 6人版250分火力翻倍但目标变大——环境精英步兵强时3人版更存活
- 深打时点：回合2-3落对方后排炮兵/占点单位——250分换掉对面300分火力位即赚
