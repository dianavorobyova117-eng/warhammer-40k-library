## 能力

### 复仇劝勉 Vengeful Exhortation（原文）
【原】"While this model is leading a unit, each time a model in that unit is destroyed by a melee attack, if it has not fought this phase, roll one D6: on a 4+, do not remove it from play. The destroyed model can fight after the attacking unit has finished making its attacks, and is then removed from play."
带队时，队内模型被近战击杀后若本轮尚未战斗：掷D6，**4+则不死**，先于移除在攻击方打完后**补一轮攻击**再移除。
→ "死前再咬一口"——20人十字军砖近乎锁定额外一轮全队输出。

### 武勇荣誉 Martial Honour（原文）
【原】"The first time a model in this model's unit makes a melee attack that destroys one or more enemy units, until the end of the battle, while this model's unit is not Battle-shocked, add 5 to this model's Objective Control characteristic."
本队首次近战击杀任意敌军单位后：**本模型OC 1→6直到终局**（只要本队不战意崩溃）。
→ 40分单位后期变OC6锁点怪。
