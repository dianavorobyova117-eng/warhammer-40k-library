## 能力

### 技术军士 Techmarine（核心）
【原】"While this model is within 3" of one or more friendly ADEPTUS ASTARTES VEHICLE units, this model has the Lone Operative ability."
3寸内有己方阿斯塔特**载具**时：本模型获得【独行者】（12寸外不可被选为目标）。

### 欧姆尼赛亚祝福 Blessing of the Omnissiah
【原】"In your Command phase, you can select one friendly ADEPTUS ASTARTES VEHICLE model within 3" of this model. That model regains up to D3 lost wounds and, until the start of your next Command phase, each time that Vehicle model makes an attack, add 1 to the Hit roll. Each model can only be selected for this ability once per turn."
你的指挥阶段：选一台3寸内己方阿斯塔特载具——**回复至多D3已损生命**，且到你下个指挥阶段前其攻击**命中+1**。每台载具每轮只能被选中一次。
→铁风暴表三技术军士＝三台载具每轮各D3修血＋命中+1。

### 欧姆尼赛亚复仇 Vengeance of the Omnissiah
【原】"If a friendly ADEPTUS ASTARTES VEHICLE model is destroyed within 12" of this model, until the end of the battle, this model's Omnissian power axe has an Attacks characteristic of 7."
12寸内己方阿斯塔特载具被毁：至战斗结束，本模型的欧姆尼赛亚动力斧**攻击变为7**。

## 战术备注
- 铁风暴矛头专属强化（均限技术军士，详见01-分队档案）：**寻的占卜网络30**（指挥阶段给6寸内一台载具全武器【致命命中】）、**欧姆尼赛亚高徒35**（每战斗轮一次：6寸内载具豁免失败可把伤害改0）、**战争机器之主20**（6寸内一台载具本轮撤退/推进后仍可射击，注意此件不限技术军士）
