## 简介
本单位可作为【领袖】加入：卡迪安突击队、卡舍津（进驻时该单位额外获得本模型的关键词）
- 【原】"While this model is leading a unit, add this model's KEYWORDS to that unit's KEYWORDS (i.e. add: INFANTRY, CHARACTER, OFFICER, CADIAN)."
- 【译】领导单位时，把步兵/角色/军官/卡迪安关键词并入该单位——**使普通突击队也能吃军官向命令与规则**。

## 能力

### 整队回撤 Fold Back the Ranks（原文）
【原】"While this model is leading a unit, if that unit is below its Starting Strength, each time a model in that unit makes an attack, add 1 to the Hit roll."
【译】领导单位低于初始编制时，该单位模型的攻击命中掷骰+1。
→**损血即狂暴**：刻意不吃医疗包，残队反而打得更准。

### 虔诚煽动家 Pious Demagogue（原文）
【原】"Once per battle, when you target this model's unit with a Stratagem, gain 1 Command point."
【译】每场一次：用战略指向本模型所在单位时，回复1CP。
